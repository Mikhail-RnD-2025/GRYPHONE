# GPYPHONE - React Frontend

Современный фронтенд для системы мониторинга RTSP потоков на базе React + TypeScript + Vite.

## 🚀 Возможности

- **Просмотр RTSP потоков** через HLS с использованием hls.js
- **Мониторинг состояния** камер в реальном времени через SSE
- **Управление камерами**: включение/выключение, добавление комментариев
- **Адаптивный дизайн** для десктопов и мобильных устройств
- **TypeScript** для типобезопасности
- **Vite** для быстрой разработки и сборки

## 📦 Установка

```bash
npm install
```

## 🛠️ Разработка

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

## 🏗️ Сборка

```bash
npm run build
```

Собранные файлы будут в папке `dist/`.

## 🔌 API Integration

Фронтенд взаимодействует с бэкендом через следующие эндпоинты:

- `GET /api/data` - получение списка камер и наборов
- `GET /api/stream_status` - SSE поток статуса камер
- `POST /api/toggle_camera` - включение/выключение камеры
- `POST /api/camera_comment` - сохранение комментария к камере

## 🎨 Технологии

- **React 19** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик
